# SALVE A FLORA 🌳

Jogo educativo para navegador sobre a proteção da flora brasileira.

**Jogue:** https://salve-a-flora.vercel.app

## Como jogar
- 🌱 Toque no **solo** para plantar uma muda (gasta 1 semente).
- 🔥 Toque no **fogo** para apagar (gasta 1 de água) antes que a árvore vire cinzas e o fogo se espalhe.
- 🗑️ Toque no **lixo** para recolher (ganha 1 semente).
- 🚜 Toque no **trator** para expulsá-lo antes que derrube as árvores.
- 🎯 Atinja a meta de cobertura florestal antes do tempo acabar, sem deixar a saúde da natureza chegar a zero.

São 5 fases (Mata Atlântica, Cerrado, Floresta de Araucárias, Pantanal e Amazônia), com curiosidades sobre a flora entre as fases.

## Estrutura
- `index.html` – página e interface
- `css/style.css` – estilos (funciona no celular e no computador)
- `js/game.js` – lógica, desenhos e sons do jogo (sem dependências externas)
